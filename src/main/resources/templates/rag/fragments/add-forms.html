    Importar do GitHub

    Clone um repositório via HTTPS ou importe links diretos de arquivos Markdown/HTML

    Uma pasta por linha (caminho relativo à raiz do repositório). Deixe em branco para importar todas as pastas.

    O repositório será clonado usando o token GitHub configurado nas propriedades da aplicação. Somente arquivos .md serão ingeridos no RAG.

    Um link por linha. Links do GitHub (blob) são convertidos automaticamente para URL raw. Formatos aceitos: .md, .html e outros suportados pelo Tika.

    O conteúdo de cada link será obtido via HTTP e ingerido no RAG. Links inválidos ou inacessíveis serão reportados individualmente no resultado.

    Importar do Confluence

    Busca páginas de um Space e ingere o conteúdo no RAG

    A chave do Space é exibida na URL do Confluence (ex: /wiki/spaces/PROJ)

    Informe um ID por linha. O ID da página aparece na URL do Confluence (ex: /wiki/spaces/PROJ/pages/123456)

    A importação usará as credenciais Confluence configuradas nas propriedades da aplicação (CONFLUENCE_BASE_URL, CONFLUENCE_EMAIL, CONFLUENCE_API_TOKEN). Somente o conteúdo de texto das páginas será ingerido no RAG. Um intervalo de 500ms é aplicado entre as requisições para não sobrecarregar o servidor.

    Importar do Monday

    Busca itens de um Board e ingere o conteúdo no RAG

    O ID do Board é exibido na URL do Monday (ex: /boards/1234567890)

    Informe um ID por linha. O ID do item aparece na URL do Monday (ex: /boards/1234567890/pulses/9876543210)

    A importação usará as credenciais Monday configuradas nas propriedades da aplicação (MONDAY_API_TOKEN). Um intervalo de 500ms é aplicado entre as requisições para não sobrecarregar o servidor. Erros de rate limiting são tratados com retry automático (até 3 tentativas).

    Busca arquivos em um bucket S3 e ingere o conteúdo no RAG

    Nome exato do bucket S3 a ser importado

    Se informado, somente arquivos nessa pasta e subpastas serão processados. Se vazio, todos os arquivos do bucket serão extraídos

    Selecione ao menos um formato de arquivo.

Um intervalo de 500ms é aplicado entre as requisições. Erros de rate limiting são tratados com retry automático (até 3 tentativas).
